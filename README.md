# 🏡 StayFinder Vacation Rentals Platform

An interactive web application built with React, Vite, and Tailwind CSS designed to replicate a high-end property booking platform experience.

## ✨ Core Features
* **Interactive Navbar:** Includes a responsive "More" dropdown selection box on mobile and desktop viewports.
* **Smooth Smooth Carousels:** Customized scroll tracks for location-based listing clusters like "Popular homes in Varanasi".
* **Ref-Based Navigation:** Custom navigation buttons that communicate directly with underlying DOM elements for flawless horizontal card sliding.

## 🛠️ How to Run This Project Locally

To get this app running on your computer, open your terminal and run these commands one by one:

1. **Clone this repository to your machine:**
   ```bash
   git clone [https://github.com/sheelamahato27-ship-it/Airbnb-Clone.git](https://github.com/sheelamahato27-ship-it/Airbnb-Clone.git)

2. Move inside the project folder:
    Bash
      cd Airbnb-Clone

3. Install all the required styling and React packages:
      Bash
        npm install

4. Boot up your local Vite development server:
     Bash
        npm run dev
